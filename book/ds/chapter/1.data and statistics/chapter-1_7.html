Chapter 1.7

Z-Score & Standardization

15 min read Intermediate Statistical Methods

The Z-score is a powerful statistical tool that tells us how many standard deviations a data point is from the mean. It's essential for comparing values from different distributions and detecting outliers.

What is a Z-Score?

The Z-score, also known as the standard score, is a statistical measure that indicates how many standard deviations a specific data point is away from the mean of the population.

Key Insight: A Z-score standardizes values, allowing us to compare data from different scales or distributions on a common scale.

The Z-Score Formula

The Z-score is calculated using the following formula:

$$z = \frac{x - \mu}{\sigma}$$

Where:

$z$ (Z-score)

The standardized value (number of standard deviations from the mean)

$x$ (Data Point)

The individual value you're examining

$\mu$ (Mean)

The population mean (average of all values)

$\sigma$ (Std Dev)

The population standard deviation (measure of spread)

Interpreting Z-Scores

Understanding what Z-scores tell us:

Z = 0

The data point is exactly at the mean. No deviation from the average.

Z > 0 (Positive)

The data point is above the mean. Higher than average value.

Z < 0 (Negative)

The data point is below the mean. Lower than average value.

"The absolute value of the Z-score tells you how unusual the data point is. A Z-score beyond ±3 is considered extremely rare in a normal distribution."

— Statistical Principle

Worked Example: Computing Z-Scores

Let's calculate Z-scores for the dataset: [1, 3, 5, 7, 9]

1

Calculate the Mean

$$\mu = \frac{1 + 3 + 5 + 7 + 9}{5} = \frac{25}{5} = 5$$

2

Calculate the Standard Deviation

$$\sigma = \sqrt{\frac{(1-5)^2 + (3-5)^2 + (5-5)^2 + (7-5)^2 + (9-5)^2}{5}} \approx 2.83$$

3

Calculate Z-scores for Each Value

For $x = 1$: $z = \frac{1-5}{2.83} = -1.41$

For $x = 3$: $z = \frac{3-5}{2.83} = -0.71$

For $x = 5$: $z = \frac{5-5}{2.83} = 0.00$

For $x = 7$: $z = \frac{7-5}{2.83} = 0.71$

For $x = 9$: $z = \frac{9-5}{2.83} = 1.41$

Results Summary

Value ($x$) Deviation ($x - \mu$) Z-Score Interpretation
1 -4 -1.41 1.41 SD below mean
3 -2 -0.71 0.71 SD below mean
5 0 0.00 Exactly at mean
7 +2 +0.71 0.71 SD above mean
9 +4 +1.41 1.41 SD above mean

Applications of Z-Scores

1. Outlier Detection

Values with $|z| > 3$ are typically considered outliers. The empirical rule states that 99.7% of data falls within ±3 standard deviations in a normal distribution.

2. Comparing Different Scales

Compare test scores from different exams, heights and weights, or any variables measured on different scales by converting to Z-scores.

3. Standardization for ML

Many machine learning algorithms perform better when features are standardized (transformed to have mean=0 and std=1).

4. Probability Calculations

Use Z-scores with the standard normal distribution table to calculate probabilities and percentiles.

Python Implementation

Here's how to calculate Z-scores in Python:

import numpy as np
from scipy.stats import zscore

# Method 1: Manual calculation
data = [1, 3, 5, 7, 9]
mean = np.mean(data)
std = np.std(data, ddof=0)  # Population std

z_scores_manual = [(x - mean) / std for x in data]
print("Manual Z-scores:", z_scores_manual)

# Method 2: Using scipy
z_scores_scipy = zscore(data, ddof=0)
print("Scipy Z-scores:", z_scores_scipy)

# Output:
# Manual Z-scores: [-1.41, -0.71, 0.00, 0.71, 1.41]
# Scipy Z-scores:  [-1.41, -0.71, 0.00, 0.71, 1.41]

The Empirical Rule (68-95-99.7 Rule)

For normally distributed data, Z-scores help us understand the probability of observing certain values:

Within ±1 SD

68% of data falls within $-1 < z < 1$

Within ±2 SD

95% of data falls within $-2 < z < 2$

Within ±3 SD

99.7% of data falls within $-3 < z < 3$

Outlier Detection Rule: Any data point with $|z| > 3$ is typically considered an outlier, as only 0.3% of data should fall beyond ±3 SD.

Standardization (Z-Score Normalization)

Standardization transforms data to have a mean of 0 and standard deviation of 1. This is crucial for many machine learning algorithms.

Standardization Formula

For each value in the dataset:

$$x_{standardized} = \frac{x - \mu}{\sigma}$$

After standardization:

  • Mean of standardized data = 0
  • Standard deviation of standardized data = 1

Practice Problem

Try It Yourself

Problem: A student scored 85 on a test where the class average was 75 with a standard deviation of 8. What is the student's Z-score?

Click to see solution

Solution:

Given: $x = 85$, $\mu = 75$, $\sigma = 8$

$$z = \frac{85 - 75}{8} = \frac{10}{8} = 1.25$$

Interpretation: The student scored 1.25 standard deviations above the class average, which is better than approximately 89% of the class.

Key Takeaways

  • Z-scores standardize data to a common scale
  • $|z| > 3$ typically indicates an outlier
  • Positive Z = above mean, Negative Z = below mean, Z = 0 is at mean
  • Essential for comparing different datasets and outlier detection
  • Foundation for many machine learning preprocessing techniques
